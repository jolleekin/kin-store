# Support

Kin Store is maintained by a single maintainer in their spare time. There's no
SLA on response times, but here's where to go depending on what you need.

## Ask a question / discuss an idea

Use [GitHub Discussions](https://github.com/kintools-dev/store/discussions) for
usage questions, design discussions, and anything that isn't a confirmed bug or
a concrete feature request.

## Report a bug

Open a
[bug report issue](https://github.com/kintools-dev/store/issues/new/choose) with
a minimal reproduction. Check existing issues and Discussions first.

## Request a feature

Open a
[feature request issue](https://github.com/kintools-dev/store/issues/new/choose),
or start a Discussion first if the idea needs more back-and-forth before it's
concrete.

## Report a security vulnerability

Don't open a public issue. See [SECURITY.md](./SECURITY.md).

## Documentation

The [documentation site](https://kinstore.dev) covers guides, plugin docs, and
comparisons with other state libraries. Each package also has its own README
(`core/README.md`, `plugins/README.md`, `react/README.md`).
